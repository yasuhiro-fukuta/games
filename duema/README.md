# トランプデュエル — duema

トランプで遊ぶデュエマ風カードバトル。あなた vs CPU、どちらも54枚フルデッキ(4色×13+JOKER2枚)。
`index.html` をブラウザで開くだけで遊べる(ビルド不要・依存ゼロの1ファイル構成)。

## ルール

- デッキ54枚、シールド6枚、初手5枚。先攻後攻はランダムで、先攻も1ターン目からドローあり
- **手札は土地としてもクリーチャーとしてもプレイできる**
  - 土地は1ターンに1枚。タップでそのスートのマナ1を出す
  - クリーチャーのコスト = 自スート1マナ + 数字ぶんの無指定マナ(例: ♠3 → 合計4マナ)
  - パワー/タフネス = 数字。出したターンは攻撃できない(召喚酔い)
- **タイミング**: クリーチャーの召喚・JOKER呪文・土地のセットは、自分のターン中ならいつでも(攻撃後でも)可能
- **攻撃**: 相手プレイヤー(シールドブレイク)or タップ中の敵クリーチャー。
  同じクリーチャーを複数のクリーチャーで攻撃してもよい(ダメージが蓄積して討ち取れる)。
  防御側はアンタップのクリーチャーでブロックできる。
  アンタップ状態のクリーチャーは、攻撃またはブロックするとタップ状態になる(次の自分のターン開始時にアンタップ)
- **A(エース)**: J・Q・K との戦闘時 +13/+0 の修正を受ける(絵札を討ち取るが、自分も刺し違えて倒れる)
- **J/Q/K の生贄召喚**: J・Q・K を召喚する際、望む数の同スートの味方クリーチャーを生贄に捧げてよい。召喚コストはその数字の合計分だけ軽減される
- **J/Q/K はシールドトリガーを持たない**(ブレイクされても手札に加わるだけ)
- **ダメージ蓄積**(デュエマルールのみ): 戦闘ダメージはターン終了時まで蓄積し、累計がタフネス以上になったクリーチャーは破壊される。ターン終了時にダメージは全回復
- **シールドの固定位置**: シールドは6つの固定位置に置かれ、割れた位置は歯抜けのまま。攻撃時は**相手のシールドカードを直接クリック**して割る位置を選ぶ(ダイヤクラックの生贄・破壊位置は唱えた側がポップアップで選ぶ)
- **シールドトリガー**: ブレイクされたカードは手札へ。そのままコストなしで召喚してもよい(JOKERは手札に加わるだけ)。**Sトリガーで場に出たクリーチャーは、次の相手のターン終了時に墓地に送られる**
- **JOKER**(すべて0マナ+追加コスト):
  - モックスジョーカー: **相手より土地が少ないときのみ**、タップで4色どのマナも出せる0マナアーティファクトとして置ける(1ターン1枚の土地セット権は消費しない)
  - ♠スペードスピア: 自クリーチャー1体を生贄 → 対象のクリーチャー1体破壊
  - ♥ハートブレイク: 自分の山札を♥が捲れるまで墓地へ落とし、捲れた♥の数字ぶん相手の山札を墓地へ(♥が出なければ自滅)
  - ♦ダイヤリコール: 手札の♦カード1枚を捨てる → 3枚ドロー
  - ♣クローバーウィル: 自分の♣土地1枚を手札に戻す → 手札のカード1枚をアンタップ状態で土地にセット(セット権不要)
- **後攻補正**: 後攻は1回だけフリーマリガン(手札5枚を山札に戻してシャッフルし、5枚引き直し)できる。あなたが後攻のときは開始時に引き直すかどうか選べる
- **勝利条件**: シールドが0の相手に攻撃を通す(ダイレクトアタック)。山札が尽きたら負け。ゲームに負けた側の手札は結果画面で公開される(両ルール共通)



## マジックルール(モード選択)

タイトル画面で「デュエマルール」「マジックルール」を選べる(オンラインは部屋を作る側が決定)。
マジックルール(MTG風)の相違点:

- **初手7枚・シールドなし・シールドトリガーなし。勝利条件はデッキアウトのみ**(山札が0枚になった瞬間に敗北。両者同時なら引き分け)。先攻の1ターン目はアンタップフェイズ(アンタップ&ドロー)を飛ばす
- **ダイレクトアタック**が通ると、攻撃クリーチャーの数字ぶん相手の山札が墓地に落ちる
- **フェイズ制**: ☀クリンナップ&アンタップ&ドロー(敵味方全ての戦闘ダメージを回復→アンタップ→ドロー)→ ⚔アタック(**土地・呪文・召喚も可能**+全攻撃を一括宣言)→ ⛨ブロック(**相手が**指定+♥の瞬速召喚(♥A含む)も使える)→ ✦戦闘解決 → ⚚メイン(土地・呪文・召喚)=ターン終了。フェイズトラッカーは自ターン=オレンジ/相手ターン=青、⛨だけ相手側の色
- **多重ブロック可**: 1体の攻撃を複数のクリーチャーでブロックできる。攻撃側のダメージは数字の大きいブロッカーへ優先して致死分ずつ割り振られ、余りは次のブロッカーへ。ブロッカー全員のパワーが攻撃側に返る。召喚酔いなし
- **ダメージは次のクリンナップ(次ターンのアンタップ直前)まで蓄積**する(数字以上で破壊)。同一の対象(タップ中のクリーチャー・本体とも)へ複数のクリーチャーで攻撃できる
- **A(エース)は1/1のETB蘇生クリーチャー**(コスト=自スート1マナ+無色Xマナ。Xは召喚時に選ぶ・0でも可。土地にもできる): スートのキーワードを持ち、**場に出たとき、自分の墓地にある同スートのクリーチャーを、数字の合計がX以下になるように望む数だけ場に出す**(例: X=5なら♠2と♠3をまとめて釣れる。蘇生された側のETBは誘発しない)。♥Aは瞬速で相手のブロックフェイズにも唱えられる
- **召喚酔いあり**(出したターンは攻撃できない)。**タップ状態で戦闘フェイズを終えたクリーチャーはパワー0**になり、アンタップで元に戻る
- **スート能力**: ♠挑戦(攻撃時、アンタップの相手クリーチャー最大1体を対象に取り、強制的にそのブロックへ参加させる。複数ブロック時は挑戦対象へ最優先でダメージを割り振る)/ ♥瞬速(相手のブロックフェイズに召喚できる)/ ♦警戒(各戦闘フェイズ後にアンタップする)/ ♣速攻(召喚酔いしない)
- **絵札(J/Q/K)の追加能力**: ♣猪突(2体以上のクリーチャーにはブロックされない)/ ♠貫通(余剰戦闘ダメージが当初の攻撃対象へ)/ ♦飛行(飛行を持たないクリーチャーにはブロックされない)/ ♥絆魂(与えたダメージぶん、墓地の上から山札に加えて切り直す。墓地の枚数が上限)
- **JOKER**(2つの使い方から選ぶ・アリスルール共通): ミシュラズジョーカー=0マナ呪文・1枚引く / ロータスジョーカー=セット権を使わず土地としてセット(相手より土地が少ないときのみ)。タップで無色3マナ、ターン終了時に破壊

## 遊戯王ルール(モード選択)

タイトル画面で選べる第3のモード(オンラインは部屋を作る側が決定)。マナなし・召喚酔いなしの遊戯王風:

- **初手5枚・シールドなし・マナなし。勝利条件はデッキアウトのみ**(山札0枚で即敗北・両者同時なら引き分け)。後攻は1回フリーマリガン可。**先攻の1ターン目はバトルフェイズなし**
- **ダメージ = 山札**: 戦闘ダメージを受けると、その数字ぶん山札が墓地に落ちる。**回復** = その数字ぶん墓地の下(古い順)から山札の下に戻す(墓地の枚数を上回れない)
- **フェイズ進行**: ドロー → メイン(召喚・セット・罠・JOKER・表示形式変更)→ バトル → ターン終了
- **召喚は1ターン1回**(表側攻撃表示 or 裏側守備表示セット)。**数字7〜10は生贄1体、J/Q/Kは2体、Aは3体**(Aは最上級・攻守14)。召喚酔いなし=出したターンから攻撃できる
- **表示形式**: 攻撃表示(縦)/守備表示(横)。裏側セットは自分にだけ「R」マーク付きの表で見える(相手からは裏)。表示変更・反転召喚はメインに1体1回(出したターンは不可)
- **戦闘**: 攻撃表示同士 → 低い方が破壊され、差の枚数が持ち主の山札から墓地へ(同値は相討ち)。守備表示への攻撃 → 上回れば破壊(山札は減らない)、下回れば差が攻撃側に跳ね返る。裏側を攻撃するとリバース(公開)。**相手モンスターが0体なら直接攻撃**(数字ぶん山札へ)
- **罠**: 手札を何枚でも罠として伏せられる(最大5枚・数字は相手に見えない)。**自分の数字以下の攻撃**が宣言されたとき発動できる(1攻撃に1枚)。スートで効果が決まる:
  - ♠**奈落の落とし穴**: 攻撃モンスターを破壊
  - ♥**恵みの雨**: 攻撃無効+罠の数字ぶん回復
  - ♦**魔法の筒**: 攻撃無効+攻撃モンスターの数字ぶん相手(攻撃側)の山札を墓地へ
  - ♣**停戦協定**: 攻撃無効+攻撃モンスターを守備表示に
- **スート能力**: ♠**貫通**(守備表示を破壊したとき超過分のダメージ)/ ♥**慈悲**(戦闘破壊されたとき数字の半分(切り上げ)回復)/ ♦**叡智**(表側で場に出たとき1ドロー)/ ♣**供物**(生贄にするとき2体分)
- **JOKER**: 死者蘇生(墓地のモンスター1体を表側攻撃表示で特殊召喚)or 強欲な壺(2ドロー)

## ポケカルール(モード選択)

タイトル画面で選べる第4のモード(オンラインは部屋を作る側が決定)。マナなしのポケカ風:

- **初手5枚・サイド6枚**。手札にたねが無ければ強制引き直し(そのたび相手が1枚ドロー)。**先攻の1ターン目はワザを使えない**
- **勝利条件は3つ**: ①サイド6枚を取り切る ②相手の場からポケモンがいなくなる ③相手の山札切れ(0枚で即敗北)
- **進化ライン**: 2〜6=たね → 7〜10=1進化 → J/Q/K=2進化(同スートの下の段に重ねる。ダメージ引き継ぎ)。**A=伝説のたね**(攻守14、倒されるとサイド2枚)。進化は1体1ターン1回、場に出したターンは不可
- **HP=数字×2、ワザのダメージ=数字**。ダメージは回復しない。**相性**: ♥>♣(精神>肉体)/♣>♦(土>セラミック)/♦>♠(剛性>剣)/♠>♥(悪意>良心)。有利なら2倍、不利なら-3
- **エネルギー**: 手札を1ターン1枚ポケモンに付ける(スートが色)。ワザにはたね1個/1進化2個/2進化3個/A4個(うち1個は自スート)
- **フェイズ**: ドロー → メイン(ベンチ最大5・進化・エネルギー・にげる・JOKER)→ バトル場の1体がワザを1回(相手のバトル場のみ)→ エンド
- **きぜつ**: エネルギーごとトラッシュ。倒した側はサイドを1枚(Aは2枚)手札に回収し、相手はベンチから昇格
- **にげる**(1ターン1回): エネルギーをトラッシュしてベンチと交代(**たね0・1進化1・2進化2・Aは1**)
- **JOKER=トレーナーズ**: 博士の研究(手札を全て捨てて5枚引く)/ ふしぎなアメ(場のたねに同スートの2進化を直接重ねる)/ ポケモン回収(自分のポケモン1体を進化カード・エネルギーごと手札に戻す)

## マジックルール(アリス)(モード選択)

マジックルールの変種(第5のモード)。進行は同じだが、**両者ともアリスの特殊カード**でデュエルする。アリスカードは通常のスート能力・絵札能力の代わりに数字の帯ごとの能力を持つ:

| スート | 2〜6 | 7〜10 | J〜K(ETB=場に出たとき) |
|---|---|---|---|
| ♥ | 飛行 | T: 1枚引く | クリーチャー1体をオーナーの手札へ |
| ♠ | 接死 | トランプル | 対象に+X/+0(X=パワー) |
| ♣ | T: ♣マナ1点 | 威迫(2体以上でしかブロック不可) | 数字X以下の土地をクリーチャー化 |
| ♦ | 絆魂(墓地→山札の下) | 反撃(タップでもパワー0にならない) | 全クリーチャーに-X/-X(ターン終了時まで) |

アリスカードも**基本スート能力(♠挑戦/♥瞬速/♦警戒/♣速攻)を持つ**(通常の絵札能力だけが帯能力に置き換わる)。タップ能力は召喚酔い中は使えない。A(1/1・ETB蘇生)とJOKERは共通。アリスカードは黒地(黒スート=白字・赤スート=赤字)で表示され、マジック・アリス共通で**カードを右クリックするとテキストを参照**できる。

## ストーリーモード「アリス・イン・アンダーランド」

タイトルの「ストーリーモード」から。ルールを選び(現在はマジックルールのみ)、名前を決めるとゲーム開始。
フィールド画面(矢印キー/WASDで移動、クリックで文送り)と戦闘画面(トランプデュエルの対戦)を往復する。
永遠の眠りに閉じ込められた主人公が、ウサギ紳士たちを倒してアリス様のもとへ進む。戦闘に敗れるとゲームオーバー(タイトルへ)。第3の部屋では**アリス本人**が待つ — 話しかけると台詞もなく戦闘が始まり、アリスだけが特殊カード(アリスルールのカード)を使う。勝てば to be continued。

## マナ支払いの自動/手動(デュエマ・マジック)

盤面右下の「支払: 自動/手動」トグルで切り替え。手動では、召喚時にタップする土地を自分でクリックして選び「支払い決定」で確定する(支払い操作中はトグル・他の操作はロック)。選んだ土地はアクションに載ってオンライン対戦でも両者の盤面が一致する。

## オンライン対戦(Firebase)

決定論エンジン+アクションログ同期(ロックステップ)方式。同じシードと操作列から両ブラウザが同一盤面を再現するため、Firebase Realtime Database には「操作」だけが流れる(無料枠で十分)。

- タイトル画面 →「部屋を作る」→ 5文字コードを相手に伝える → 相手が「部屋に入る」
- リロードしてもアクションログの再生で盤面が復元される
- `index.html` 冒頭の `FIREBASE_CONFIG` に Firebase プロジェクトの設定を入れると有効になる(未設定の間はCPU対戦のみ)

### Firebase セットアップ

1. https://console.firebase.google.com → プロジェクト作成(Analytics不要)
2. 構築 → Realtime Database → データベース作成(ロケーションは asia-southeast1 など、テストモードで開始)
3. ルールを以下に変更(部屋データのみ読み書き可):
   ```json
   { "rules": { "rooms": { "$code": { ".read": true, ".write": true } } } }
   ```
4. プロジェクト設定 → マイアプリ → ウェブアプリを追加 → 表示される `firebaseConfig` を `index.html` の `FIREBASE_CONFIG` に貼る

## 操作

手札をクリック → 土地に置く / 召喚 / JOKER呪文を選択。攻撃は自分のクリーチャー→対象の順、ブロックはブロックさせる自分のクリーチャー→相手の⚔の順にクリック。
