「このように、ターンを交代しながら進めます。1ターンには5つのフェイズがあります。」
「フェーズ1、アンタップフェイズ。タップしたカードを起こし、1枚引きます。」

「そしてフェーズ5、クリンナップフェイズ。クリーチャーの傷はすべて癒え、ターンが移ります。」

## 設計メモ

- 検算: ウサギ山札 47 −ドロー9 −被ミル22(T4:2 + T5:3 + T6:8 + T7:9)=16 → T10の♥J+♣J=22点で討ち取り。プレイヤー山札 47−9−8(♣4×2回)=30で安全圏
- 網羅した教習: セット/召喚/攻撃/ブロック/フェイズ送り/エース(X≧1)/タップ中クリーチャーへの攻撃とその防衛/ダメージ=山札/クリンナップ回復/タップの隙(パワー0)/♠挑戦/♥瞬速/♦警戒/♣速攻/モックスジョーカー(ウサギの実演)/現出=生贄召喚(瞬速との複合も)/多重ブロック+挑戦の優先割り振り/チャンプブロック(ウサギの実演)
- 台詞では生贄召喚を「現出」と呼ぶ(UI・ログの表記は「生贄召喚」のまま)
- 実装: 積み込みデッキ+誘導システム(対象だけ発光・他入力ロック)+ウサギ台詞ポップアップ(`index.html` の `TUT_P`(41手)/`TUT_C`(43手))
