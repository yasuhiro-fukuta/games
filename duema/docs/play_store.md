# Google Play ローンチ手順(デュエルトランプ)

方式: **TWA(Trusted Web Activity)** — Vercelの本番サイトをそのまま包んだAndroidアプリ。
以後のゲーム更新は今まで通り `main` へのpushだけで反映される(ストア再審査不要)。

PWA側(manifest.json / sw.js / アイコン / privacy.html / assetlinks雛形)はリポジトリに準備済み。

## 0. 事前準備(あなたの作業)

1. **Google Play開発者アカウント登録** — https://play.google.com/console
   初回のみ $25。本人確認あり(数日かかることがある)
2. `duema/privacy.html` の末尾「お問い合わせ」に**公開してよい連絡先メール**を記入してpush
3. (推奨)独自ドメインを取得してVercelに設定 — 将来のAdSense広告に必須。
   ドメインを変えた場合は manifest.json/このガイドのURLを読み替える

## 1. .aab(アプリ本体)の生成 — PWABuilderを使う

1. https://www.pwabuilder.com を開き、`https://games-three-sepia.vercel.app/duema/` を入力
2. スコアを確認(manifest/sw検出済みのはず)→ **Package for Stores → Android**
3. 設定:
   - Package ID: `com.fromscratch.dueltrump`
   - App name: `デュエルトランプ` / Short name: `デュエルトランプ`
   - Signing key: **「Create new」を選ぶ**(生成される .keystore と パスワードは絶対に無くさないこと。バックアップ必須)
4. ダウンロードしたzipに `.aab`(アップロード用)と `assetlinks.json`(署名情報入り)が入っている

## 2. assetlinks の本設定(アドレスバーを消すために必須)

1. PWABuilderのzipに入っていた `assetlinks.json` の `sha256_cert_fingerprints` の値を、
   リポジトリの `/.well-known/assetlinks.json` の `REPLACE_WITH_...` と差し替えてpush
2. さらにPlay Console公開後、**Play Console → 設定 → アプリの完全性 → App Signing** に表示される
   **「SHA-256 証明書のフィンガープリント」も配列に追加**する(Playが再署名するため2つ必要):
   `"sha256_cert_fingerprints": ["PWABuilderの値", "Play Consoleの値"]`
3. 確認: `https://games-three-sepia.vercel.app/.well-known/assetlinks.json` が開ければOK

## 3. Play Console でアプリ作成

1. 「アプリを作成」→ 名前: デュエルトランプ / デフォルト言語: 日本語 / アプリ / 無料
2. **クローズドテスト**トラックに .aab をアップロード
   - ⚠ 個人アカウントは**テスター12人以上×14日間のクローズドテスト**を経ないと製品版公開を申請できない。
     友達に配る予定の人たちをテスターリスト(メールアドレス)に登録する
3. ストア設定で埋めるもの:
   - アプリ内購入なし / 広告なし(現状) / カテゴリ: ゲーム>カード
   - **プライバシーポリシーURL**: `https://games-three-sepia.vercel.app/duema/privacy.html`
   - コンテンツレーティング(IARC質問票): 暴力=カードバトルの抽象表現のみ。ユーザー間交流=あり(オンライン対戦)
   - **データセーフティ**: 「データを収集する」= メールアドレス・ユーザーID(Googleログイン時のみ・アプリ機能のため・暗号化送信・削除リクエスト可)。ゲスト時は収集なし
4. ストア掲載情報(下書きは後述)+ スクリーンショット(スマホ縦2枚以上)、
   アイコン512px(`duema/icon-512.png` がそのまま使える)、フィーチャーグラフィック1024x500

## 4. 公開までの流れ

クローズドテスト開始 → 14日間+テスター12人維持 → 「製品版への昇格を申請」→ 審査(数日)→ 公開

・勝てばパックがもらえる。絵違いカードを集めてデッキを飾ろう

無料・買い切り要素なし。登録不要のゲストプレイ対応(Googleログインでデータ引き継ぎ)。
